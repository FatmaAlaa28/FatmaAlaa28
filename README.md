## ⚖️ Featured Project — ArchiQ

<table>
<tr>
<td width="100%">

**ArchiQ** is an AI-powered LegalTech platform built with **Angular** and **ASP.NET Core**. It combines modern software architecture with AI/RAG capabilities to help users interact with legal knowledge through evidence-based answers.

The platform includes:

- 🤖 AI-powered legal chatbot
- 🔍 RAG (Retrieval-Augmented Generation) pipeline
- 🧠 Semantic search with vector embeddings
- 📄 Legal document processing & OCR
- 🏗️ Clean Architecture & CQRS
- 🔐 Secure backend APIs
